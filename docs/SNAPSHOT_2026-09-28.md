## この時点で入っているもの

- 色は4色だけ: 紙 `#EDEDED` / 墨 `#171717` / 灰 `#444444` / 赤 `#DA0037`（赤は未納・強調・下線）
- **経堂マスタ K〜O**: 入会／退会／月初／月末の計画対実績。表の数字（B〜F）から SPARKLINE で描く。月ラベルは `5月`。J列は対前月の数字（謎の「5ヶ月」矢印は無し）
- **未納管理_推移**: KPI → 月別表 → その下に 2×2（未納総額と回収額／回収率／件数／1ヶ月・2ヶ月・貸倒）。表の C/D/E/B/I/J/K 列を直接参照
- **未納管理**・**入会者一覧**: チェック・名前などは installed onEdit で元ブックへ自動写し戻し。メニュー「チェックを元へ反映」は予備
- 経堂マスタ P列以降は当月の申請パネル（分野切替）。学割・紹介の当月件数KPIあり
- 日報の送信トリガーは再作成していない

## グラフが空枠だった理由（残す）

Sheets の埋め込みグラフは、非表示列・極細列・日付扱いの「25年8月」だと **タイトルだけの灰枠** になった。ヘルパー列を見える数字にしても同じ。  
そのため埋め込みは捨てて、**セル上の SPARKLINE**（数値に連動、スクショではない）に切り替えた。

再構築 API:

- `setupMasterKpiCharts` … 経堂マスタの4カード
- `fillUnpaidTrendNow` … 未納推移の表＋カード
